  • Simplified the layout structure for better reliability

Expected Behavior:

  • Dropdown opens with consistent 250px height for options area

  • Search bar stays fixed at top while options scroll below

  • Custom styled scrollbar (thin, gray) for better UX
  • No horizontal scrolling, content truncates properly
